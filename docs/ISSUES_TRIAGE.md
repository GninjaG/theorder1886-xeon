O GitHub não exigiu autenticação para essa leitura. Não baixei nem alterei anexos; links abaixo preservam o local original. ## Anexos e como pedir evidência

Os links levam aos anexos originais do GitHub; esta triagem não fez download nem salvou cópias locais. Logs podem conter caminhos/identificadores de usuário: compartilhar somente com o autor ou em local consentido. Não pedir dumps de jogo, firmware, chaves nem saves públicos; para defeitos de capítulo, pedir instruções para reproduzir com save local privado ou frame capture reduzido.

Pedir nova evidência quando o item não tem versão/driver/cena/log, quando a única evidência precede a correção alegada, ou quando há múltiplas GPUs/sintomas no mesmo issue. Solicitação mínima padrão: versão/hash do port, CUSA e versão/hash do eboot, GPU/driver/OS, settings, cache cold/warm, capítulo/checkpoint/passos, `user/last_run.log` fechado após a execução, screenshot/frame capture do primeiro frame ruim e indicação de se o problema ocorre em build atual. Não pedir para apagar o perfil existente: usar perfil/diretório de teste isolado.

Para #29, pedir confirmação pós-0.7.5 e save/tempo do vídeo; para #30 pedir cenário de combate/save e um frame de vertex explosion; para #26 pedir o frame da cascata solar; para #36/#39 pedir a primeira aparição do artefato e captura do pass; para #40 pedir telemetria por thread/RAM/VRAM após 30 min; para #11 o log de OOM com callsite, RAM/pagefile e GPU budget; para #1/#10 logs por device e personagem; para #24/#7 separar SKU e reporter; para #37/#38 pedir settings/mapeamentos e comportamento A/B.
